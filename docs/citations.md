# Tool citations and upstream projects

Before publishing a scientific analysis, cite every enabled tool and record its
version. Primary project links:

- Nextflow: <https://github.com/nextflow-io/nextflow>
- nf-core modules: <https://github.com/nf-core/modules>
- nf-core/mag reference architecture: <https://github.com/nf-core/mag>
- FastQC: <https://github.com/s-andrews/FastQC>
- fastp: <https://github.com/OpenGene/fastp>
- minimap2: <https://github.com/lh3/minimap2>
- samtools: <https://github.com/samtools/samtools>
- SPAdes: <https://github.com/ablab/spades>
- QUAST: <https://github.com/ablab/quast>
- CheckM2: <https://github.com/chklovski/CheckM2>
- GUNC: <https://github.com/grp-bork/gunc>
- GTDB-Tk: <https://github.com/Ecogenomics/GTDBTk>
- MultiQC: <https://github.com/MultiQC/MultiQC>
- sourmash: <https://github.com/sourmash-bio/sourmash>
- dRep: <https://github.com/MrOlm/drep>
- inStrain: <https://github.com/MrOlm/inStrain>

This list is a navigation aid, not a substitute for the citation instructions
distributed with each selected release.
